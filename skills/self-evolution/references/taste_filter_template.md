# Taste Filter 打分模板

## 五维评分表

| 维度 | 判断问题 | 分数(1-5) |
|------|----------|-----------|
| 相关性 | 和核心关注方向/当前项目相关吗？ |  |
| 当前价值 | 是否服务最近的任务或决策？ |  |
| 深度 | 是否有方法论、案例或实践细节？ |  |
| 可转化性 | 能否变成 Memory / Skill / 可复用素材？ |  |
| 新鲜度 | 是否提供了之前不知道的视角？ |  |
| **总分** | | /25 |

## 处理决策

| 总分 | 动作 |
|------|------|
| 20-25 | 精读并蒸馏 |
| 15-19 | 快速阅读并记录 |
| 10-14 | 暂存，不立即处理 |
| <10 | 丢弃或忽略 |

## 核心原则

不是判断"内容客观上好不好"，而是判断"对我/用户现在有没有用"。
好内容很多，但注意力有限。个人Agent首先要保护用户的注意力。
