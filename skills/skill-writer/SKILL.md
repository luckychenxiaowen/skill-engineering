# skill-writer V2.5｜人类作家·终极反检测系统

> 九层处理流程 · 三档强度 · 工业级全栈修复 · 封版稳定版
> 修复 12 项高阶漏洞：局部句嵌入平滑 / 概念共现频率 / 分层改造时序指纹 /
> 跨段因果偏移 / 排版格式指纹 / 输出编码标记 / 人机混合输入 / 动态调研碎念 /
> 合规举证痕迹 / 纯数据文本适配 / 并发任务隔离 / 内部特征混淆

## 什么时候用

用户需要让 AI 生成的文本通过 AI 检测器时触发。典型场景：
- 公众号/知乎/头条文章要过 AI 检测
- 学术论文要过 Turnitin / GPTZero
- 企业内容要过内部审计
- 矩阵账号批量发布需要差异化
- 海外 Medium / 自媒体平台发布

## 什么时候不用

- 用户只是聊"AI 检测原理" → 不触发
- 用户要压缩 API Token → 用 tokensaver / caveman
- 用户要普通润色/语法修正 → 不触发（本 Skill 专注反检测）

- Phase1.5 快照模块：提取数字 + 前后各 5 词修饰短语，Phase6 比对时检测释义偏移，偏移则阻断回滚

### 行业术语保护白名单扩展区

- 自动识别文本内 AI / 金融 / 垂直行业专有名词（Skill、Token、Agent、Embedding、RLHF、CoT、RAG、MoE 等）
- 构建动态术语保护列表，所有阶段禁止替换这些词汇

## 二、九层标准化处理流程

### Phase0：隐式水印与零宽字符前置清洗

**执行时机**：任何改写前，文本导入即执行

**操作**：
1. 扫描全文不可见字符并全部删除：
   - 零宽空格（U+200B、U+200C、U+200D）
   - 零宽连接符 / 非连接符
   - 方向控制字符（U+202A-U+202E）
   - 字节顺序标记（U+FEFF）
   - 所有 Unicode 控制字符（C0 / C1 控制码）
2. 检测字符偏移异常，标准化为纯文本格式
3. 输出纯净文本供后续流程使用

**目的**：清除大模型原生输出携带的元数据水印载体

### Phase0.5：合规标注前置插入

- 支持六模板切换 + 自定义位置 + 关闭选项
- 默认：开启 + 开头 + 国内深度辅助

### Phase1：HLD 三层模式爆破诊断

**内置检测库**：
- 33 类 AI 表层模板特征（维基 AI 清洗标准同源）
- HLD 三层语言学特征库：词层 n-gram → 句法层句式分布 → 篇章层语义连贯性
- 中文专用特征库（STYLESHIELD 适配）：模板化商业过渡词、三段式排比、闭环总结句式、情绪单一度

**输出三项诊断评分**：

| 指标 | 高风险阈值 | 人类目标区间 |
|------|-----------|-------------|
| AI 问题密度 | ＞60% | — |
| 篇章连贯熵 | ＜0.4 | ＞0.6 |
| 情绪方差 | ＜0.2 | ＞0.4 |

**段落分级标记**：
- 高风险段落 → Phase2 深度改造 + Phase4 微调候选
- 中风险段落 → 仅 Phase2 轻度改造
- 低风险段落 → 跳过改造，直接保留

### Phase1.5：白名单快照模块（含释义拦截）

1. 提取全文白名单内容（数字 + 修饰短语 + 原话 + 金句），生成规范化快照
2. 快照存储于临时变量，供 Phase6 比对
3. 改写期间白名单内容完全隔离，任何流程无权触碰

### Phase2：零 AI 纯规则重塑（全程不调用 LLM）

**2.1 句长剧烈扰动 + 局部窗口约束**：
- 全文句长标准差强制拉升至 ≥4.5
- 任意连续 5 句必须包含至少 1 句 ≤5 字的极短句 + 至少 1 句 ≥25 字的超长杂糅句

**2.2 清除 AI 模板过渡词（完整黑名单）**：
> 综上所述、由此可见、不难看出、不可否认、从某种意义上说、值得注意的是、值得一提的是、不可忽视的是、毋庸置疑、众所周知、显而易见、换言之、也就是说、具体而言、在当今时代、随着技术发展、由此不难得出、与此同时、从某种角度

**2.3 断裂式口语转场（20 条动态抽取）**：
从扩展话术库中随机抽取插入原过渡词位置

**2.4 结构留白改造 + Phase4 互斥规则**：
- 随机选取 25% 段落删除结尾结论
- **互斥规则**：被删除结论的段落，跳过 Phase4 的逻辑断层改造

**2.5 第一人称调研碎念注入（25 条动态抽取 3-6 条）**

**2.6 括号私人备注注入（15 条动态抽取 1-3 条）**

**2.7 标点仿生**：
- 随机将 10% 的句号替换为破折号
- 随机将 5% 的句号替换为省略号

**2.8 词嵌入噪声注入（修复漏洞 2）**：
- 对全文通用描述词（非专业术语、非白名单），随机选取 15%-20% 替换为同领域异构表达
- 异构表达库：每个通用词提供 2-3 套不同语义向量的行业表述
- 目的：打散全局词嵌入分布，消除平台向量匹配指纹

**2.9 局部句嵌入平滑抑制（修复漏洞 1）**：
- 每连续 3 句，随机选择 1 句替换为完全不同向量的同义表述
- 替换范围：通用修饰词、描述性短语
- 不触碰：专业术语、白名单数据、核心金句
- 目的：打破相邻句子向量平滑渐变，使局部波动符合人类写作特征

### Phase3：多层语义水印扰动

**扰动优先级（基于 Phase0 水印预检）**：
- 水印风险 ≥60 分 → 三层全量扰动
- 水印风险 30-59 分 → 仅 Token 层 + 句法层
- 水印风险 ＜30 分 → 跳过

**Token 层扰动**：低频词替换为同领域小众合理词汇

**句法层扰动**：长句拆分、短句合并、15% 句子语序倒装

**篇章层扰动**：
- 不仅处理文末参考文献列表
- **每 3 个段落插入一处轻微论证偏移**：将下一段的核心词提前至本段末尾作为预兆，或在段落中段插入一句相关但不推进论证的行业观察
- 不改变核心观点，仅打乱分段语义哈希分布

### Phase3.5：骨架随机重排（极致档开启）

**执行逻辑**：
1. 识别全文所有段落，标记三类：
   - 显性因果链段落（不可拆分）
   - 时间线叙述段落（不可打乱）
   - **隐性绑定段落**：相同企业 / 机构 / 报告 / 事件关键词，存在跨段指代关系
2. 仅完全无任何绑定关系的独立段落参与重排
3. 调换 3-5 组顺序，不破坏任何逻辑绑定

**目的**：对抗 DAMAGE / Originality.ai 跨版本溯源比对检测

### Phase3.6：概念弱关联扰动 + 概念共现频率打散（极致档开启）

**A. 论证顺序微调**：
- 将 3-5 处局部概念的论证顺序做轻微调整
- 在 2-3 处概念衔接点插入 1 句同行业无关浅概念作为缓冲节点
- 不改变核心结论、不篡改白名单数据

**B. 概念共现频率打散**：
- 识别全文高频核心概念（出现 ≥5 次）
- 将其中 20%-30% 的出现替换为同义异构表达
- 替换策略：仅替换部分出现，不全部替换，保持自然度
- 目的：降低核心概念跨段共现密度

### Phase4：统计信号 + 篇章熵联合攻击

**选取逻辑（仅对 Phase1 标记的高风险段落，累计 ≤ 全文 20%）**：
- 优先级 1：篇章连贯熵 ＜0.35
- 优先级 2：情绪方差 ＜0.15
- 优先级 3：AI 问题密度 ＞70%
- **强制分散**：选中的高风险段落，连续不超过 2 段

**4.1 全局 + 局部双层快照注入**：
- 全局核心观点快照（3-5 句，含白名单金句）
- **每段落局部观点快照**：提取该段落核心细分判断（1-2 句）
- 微调时同时携带双层快照，冲突段落自动回滚

**4.2 跨段因果快照（修复漏洞 4）**：
- 提取全文段落间对比、转折、矛盾关系
- 生成因果链快照（3-5 条核心对立关系）
- Phase6 审计时自动比对：对立关系是否被弱化 / 平滑化
- 若力度衰减超过阈值 → 自动回滚至纯规则改写

**4.3 行业术语保护**：自动锁定专业术语，禁止替换

**4.4 LLM 微调操作（仅句式 / 结构重排，内容主体不动）**：
- 插入小众行业差异化表达
- 制造局部轻微逻辑断层
- 插入自我摇摆表述

**4.5 微调后处理**：
- 每段微调完成后强制执行一次规则后处理：
  - 随机倒装 15% 的句子
  - 替换 3-5 个词为同领域小众词汇
  - 重组 1-2 句的句式结构
- 目的：打散 LLM 微调生成的隐式向量分布

**全局目标**：困惑度提升 ≥50%，篇章连贯熵 ≥0.6

### Phase4.5：词汇搭配校验

**执行时机**：Phase4 微调完成后，小众词汇替换后

**操作**：
1. 自动校验被替换词汇所在句子的主谓搭配、动宾搭配是否通顺
2. 内置常见搭配违和规则库 + 行业惯用搭配字典
3. 检测到搭配违和 → 自动退回 → 重新从异构表达库中选取下一顺位词汇
4. 最大重试 3 次，仍违和则放弃该处替换，保留原文

### Phase5：无序情绪仿生注入

**5.1 情感内核微量偏移机制**：
检测连续 3 段以上同类情感内核段落，在中间插入 1 段不超过 3 句的缓冲。

**缓冲形式三种随机切换**：

| 形式 | 占比 |
|------|------|
| A. 纯客观短句 | 33% |
| B. 轻微自我摇摆 | 33% |
| C. 简短行业补充 | 33% |

控制占比 ≤ 全文 5%，三种形式随机混用

**5.2 核心段落屏蔽规则**：
- 标记全文核心段落：含核心数据、反常识金句、结尾拷问的段落
- 禁止在核心段落内部插入任何缓冲句、题外话瑕疵
- 缓冲 / 瑕疵仅允许放置在核心段落首句之前或末句之后

**5.3 动态调研碎念生成（废弃固定库）**：
- 将碎念拆解为三类组件随机组合：
  - 主语组件：我 / 我们 / 当时 / 后来 / 说实话
  - 动作组件：核对 / 翻到 / 对比 / 找到 / 意识到 / 溯源 / 反复确认
  - 场景组件：原始报告 / 附录 B / 数据源 / 那组数字 / 采访原文 / 播客实录
- 组合空间：280 种不同结构
- 每次随机抽取 3-6 条，全文无重复句式骨架

**5.4 可控人类瑕疵植入（12 类，随机选取 2-4 类，数量 0-5 处浮动）**：
原有 6 类：语义重复、局部顿挫、开放式留白、自问不自答、轻度前后矛盾、话说到一半
新增 6 类：轻微指代模糊、临时插入题外话、数字描述口语化变体、轻微转折遗漏、同一词汇跨段无意识重复、主观感受插入客观陈述
- 允许 ≥30% 段落完全无瑕疵

**5.5 情绪过渡动态生成**：
- 通过段落末尾的标点变化（句号 → 破折号 → 问号）
- 通过下一段开头的语气词（"但。""行。""说实话。"）
- 通过段落间论证节奏突变（长段 → 极短段 → 长段）
- 不依赖任何模板化跳转句

**5.6 情绪方差硬指标**：≥0.4

### Phase5.5：纯数据短文情绪补充

**触发条件**：全文情感表达密度极低（纯数据罗列 / 无主观陈述）

**执行逻辑**：
1. 检测全文是否仅有数据堆砌、无任何情感表达
2. 自动在数据段落之间插入 2-4 条主观感慨短句
3. 占比 ≤ 全文 5%，不破坏数据中立考据属性
4. 目标：为纯数据文本提供情绪方差基础

### Phase6：多模型联合审计闭环

**6.1 白名单快照比对（含释义偏移检测）**：
- 比对终稿与快照，确保所有白名单内容 100% 一致
- 出现差异 → 阻断输出 → 自动回滚 → 重新执行

**6.2 水印信号复检**：
- 模拟 SynthID 验证逻辑，检查 token / 句法 / 篇章三层水印是否清除
- 如仍有残留 → 返回 Phase3 重新扰动

**6.3 跨段因果快照比对**：
- 验证对立 / 对比 / 转折关系是否被弱化
- 力度衰减超过阈值 → 回滚

**6.4 四重放行指标 + 自适应阈值**：

| 文本长度 | 句长标准差 | 情绪方差 | 残留率 | 水印 |
|---------|-----------|---------|--------|------|
| ＞500 字 | ≥4.5 | ≥0.4 | ≤8% | 完整 |
| 301-500 字 | ≥3.8 | ≥0.35 | ≤8% | 简化 |
| 101-300 字 | ≥3.5 | ≥0.3 | ≤10% | 简化 |
| ≤100 字 | ≥3.0 | ≥0.2 | ≤12% | 跳过 |

**6.5 动态迭代终止 + 超高风险兜底降级**：
- **动态终止**：第一轮检测全部达标 → 立即跳出
- **超高风险兜底**：3 轮后仍严重超标 → 自动切换极致档二次重跑 → 输出 + 红色高危警告
- 非严重超标 → 强制输出 + 黄色提示

**6.6 合规举证差异文档**：
- 可选模式：生成两份输出
  1. 终稿正文（纯净可发布版）
  2. 差异对比文档（标记所有机器扰动段落、人工可二次修改区域）
- 差异文档格式：Markdown 表格，左侧原文，右侧修改后，标注改动类型

### Phase7：批量任务差异化引擎

**7.1 180 天全局记忆池**：
- 引入外部随机熵：本地时间毫秒级随机值 + 文本 hash + 系统随机数
- 参数池周期 180 天，记忆池存储周期 180 天
- 180 天内使用过的模板自动过滤复用

**7.2 矩阵多账号隔离开关**：
- 开启后为每个账号分配独立参数空间：
  - 独立扰动参数区间
  - 独立 180 天记忆池
  - 独立随机种子链
- 跨账号无任何共享参数，彻底隔离统一工具指纹

**7.3 多线程并发隔离**：
- 每个并发任务分配独立随机熵种子
- 独立临时记忆池分片（非共享）
- 同批次任务之间参数完全隔离

**7.4 内部特征序列随机混淆（极致档）**：
- 非核心流程步骤随机增加 1-2 处轻量额外扰动
- 每篇额外扰动类型、位置、强度均不同
- 目的：破坏固定内部特征序列，防止第三方反向提取工具指纹

**7.5 单日产出预警**：
- ≥3 篇：黄色提示「建议拆分至次日发布」
- ≥5 篇：红色警告「存在账号级 AI 批量创作限流风险」

**7.6 流程随机置换开关（极致档）**：
- 非依赖处理层（Phase2 / 3 / 5 / 4.5）随机调换执行先后顺序

### Phase8：输出层格式 + 编码随机化

**8.1 排版格式随机化**：
- 段落空行：1-2 行随机
- 换行分割点：小幅偏移
- 小标题格式：加粗 / 未加粗随机
- 数据段落缩进：0-2 字符随机浮动

**8.2 输出编码随机切换**：
- 随机切换 UTF-8 或 无 BOM UTF-8
- 清除所有内部隐形分段控制标记
- 输出纯裸文本

**8.3 输出模式**：

| 模式 | 输出内容 |
|------|---------|
| 完整报告模式 | 终稿 + 完整评分报告 + 合规提示 + 风险预警 |
| 纯净正文模式 | 仅终稿正文 |
| 合规举证模式 | 终稿正文 + 差异对比文档 |

### Phase9：批量白名单导入

- 支持多行文本批量粘贴
- 支持 CSV 格式导入
- 自动识别并批量加入白名单锁定
- 支持导出 / 导入完整白名单配置包

## 七、Gotchas（陷阱 / 常见错误）

1. **人工原稿误用 AI 初稿模式**：用户标记为手写原稿但没切模式 → 执行了全九层扰动 → 过度人工化。**解决**：输入源双模式必须明确选择，默认 AI 初稿模式需用户确认
2. **白名单遗漏**：用户没提供完整白名单 → 核心数据 / 金句被扰动 → Phase6 审计失败回滚。**解决**：Phase1.5 自动提取白名单快照，用户可补充
3. **矩阵账号未隔离**：多账号量产但没开 Phase7.2 → 跨账号共享参数 → 被检测出统一工具指纹。**解决**：矩阵场景必须开启隔离开关
4. **单日产出超限**：单账号日产出 ≥5 篇 → 触发平台限流。**解决**：Phase7.5 自动预警，红色警告时强制停止
5. **极致档未开骨架重排**：过 Turnitin / GPTZero 但没开 Phase3.5 / 3.6 → 跨版本溯源被检出。**解决**：学术 / 企业审计场景必须用极致档
6. **纯数据文本情绪不足**：纯数据罗列 → 情绪方差 ＜0.2 → 判黄。**解决**：Phase5.5 自动检测并补充主观感慨
7. **合规标注位置错误**：默认开头但用户期望文末 → 不符合平台要求。**解决**：Phase0.5 支持自定义位置
8. **术语被替换**：专业术语（Token / Agent / RLHF）被当成通用词替换 → 行业读者看不懂。**解决**：行业术语保护白名单自动锁定
9. **核心段落被打断**：在金句 / 数据段落内部插入缓冲 → 破坏核心论证。**解决**：Phase5.2 核心段落屏蔽规则
10. **超长句生成**：改写后生成超过 32 字的句子 → 不符合人类写作特征。**解决**：Phase2.1 句长约束 + Phase6 审计拦截
